## Larangan untuk agent

- Jangan menyentuh nginx, `.env`, konfigurasi server, sertifikat, atau DB MySQL `dbsipenamas`.
- Jangan menambah dependency baru (composer/npm) tanpa persetujuan.
- Jangan menghapus/melemahkan test supaya lulus. Ubah test lama hanya bila perilakunya sengaja berubah, dan jelaskan di commit.
- Jangan push ke `main`, jangan force-push, jangan buka PR kecuali diminta.
- Jangan commit perubahan yang bukan milik task. Cek `git status` dulu.
- Kalau task terhalang, jangan menebak: lewati, catat alasannya, lanjut.

## Alur git

1. `git fetch origin main`, buat branch kerja dari `origin/main` (mis. `claude/tugas-2026-10-05`).
2. Satu commit per task, gaya repo: `feat(...)`, `fix(...)`, `chore(...)`, `docs(...)`.
3. Sebelum push:
   - Backend: `vendor/bin/pint --dirty --format agent`, lalu `php artisan test`.
   - Frontend: `npx vitest run tests/features`, lalu `npx vite build`.
4. Push branch kerja saja: `git push -u origin <branch>`.

### #12 Pilih anggota tim dari daftar dosen
- **Masalah:** di `sipenamas_v2_frontend/src/features/pen/FormUsulanPenelitianPage.jsx` anggota dosen diisi teks bebas (Nama, "NIDN / NIK", Tugas). Pengguna sering salah/lupa NIK sehingga muncul error `anggotaDosen.0.npp field is required`. Legacy memakai combobox pencarian dosen.
- **Langkah:**
  1. Cari combobox anggota tim di legacy (`pen/app.js` + `pen/myphp/cmb*.php`; kata kunci: `penelitian_tim0`, anggota, NIK/KODEPERSON). Catat filter siapa yang boleh dipilih.
  2. Backend: endpoint pencarian dosen mengikuti filter legacy. Ikuti pola endpoint yang sudah ada di `app/Http/Controllers/Api/V1/MasterDataController.php` (`/reviewer`, `/mahasiswa`: `ApiResponse` + Resource). Tambah feature test.

### #14 E2E Playwright alur penelitian
- Baca dulu `sipenamas_v2_frontend/playwright.config.js` dan `e2e/login.spec.js`, ikuti pola dan cara menjalankannya. `@playwright/test` sudah ada di `package.json`.
- **Skenario minimal:** ketua membuat & mengajukan usulan → anggota setuju → ketua isi dana penyertaan, generate & set final lembar pengesahan, upload PDF proposal, set dokumen final → Dekan melihat usulan di antrean dan menyetujui → usulan hilang dari antrean, label ketua "Disetujui Dekan, Menunggu Plotting".
- **Backend E2E:** sqlite sekali pakai + seeder `Database\Seeders\E2eAlurPenelitianSeeder`. Env var ada di komentar atas `sipenamas_v2_frontend/tests/integration/alurPenelitian.integration.test.js`: `APP_ENV=testing`, `DB_CONNECTION=sqlite`, `DB_DATABASE`, `LEGACY_RES_PATH`, `E2E_TOKEN_FILE`, `CORS_ALLOWED_ORIGINS`, `VITE_API_BASE_URL`.
- **Catatan seeder:** user seeder hanya diberi permission, belum role Spatie, sehingga `/auth/me` error 500. Perbaiki di seeder: assign role PEN/DKN/ADM/REV sesuai peran (Dekan dan reviewer juga PEN). Jangan diakali di test.
- **Login E2E:** SSO tidak tersedia. Pakai token dari `E2E_TOKEN_FILE`: set `localStorage.sipenamas_token` dan `sipenamas_user` dari `GET /auth/me`; untuk Dekan panggil `POST /auth/switch-role` dengan `{"role":"DKN"}`.
- Kalau E2E tidak bisa dijalankan di environment, tetap commit spec bila selesai ditulis tetapi nyatakan belum pernah dijalankan.
