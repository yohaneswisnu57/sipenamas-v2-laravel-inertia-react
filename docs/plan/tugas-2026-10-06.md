# Rencana Kerja SIPENAMAS V2 (2026-10-06)

## Lanjutan Simulasi & Uji Manual (User)

### #1 Selesaikan Uji Dekan
- Login sebagai Dekan Teknik.
- Cek kembali Dashboard Dekan: periksa apakah angka statistik (Pagu, Dana Disetujui, Usulan Aktif) sudah muncul dengan benar.
- Lakukan persetujuan (Approve) pada proposal yang ada di tabel antrean.

### #2 Uji Manual Siklus Revisi (#9)
Lanjut langkah 9–11:
- Login sebagai Admin/LPPM → Masuk ke **Plotting Reviewer** → Tunjuk seorang Reviewer.
- Login sebagai Reviewer → Berikan penilaian dan catatan **Revisi** pada proposal tersebut.
- Login kembali sebagai Peneliti → Tanggapi komentar dan unggah PDF Revisi.
- Login lagi sebagai Reviewer → Verifikasi dan setujui revisinya hingga status mencapai "Sidang Final LPPM".

### #3 Uji Akhir Sampai Tuntas (#11)
Setelah revisi beres:
- Lakukan Final Approval (oleh LPPM).
- Generate Surat Tugas / Surat Perjanjian Pelaksanaan (SPD). Cek isi docx (dana = `NOMINALDANA_FINAL` × 70%, kode anggaran, QR).
- Lanjutkan ke siklus pelaporan akhir (kuesioner, kelengkapan dokumen, capaian luaran).
- Persetujuan laporan akhir oleh Dekan.

- **Masalah saat ini:** di `FormUsulanPenelitianPage.jsx`, input anggota dosen masih berupa isian teks manual ("NIDN / NIK") yang rentan salah ketik sehingga API backend gagal melakukan validasi.
- **Target:**
  1. Buat endpoint baru di backend (mengikuti filter legacy `pen/myphp/cmb*.php`) untuk mencari dan memilih dosen.
  2. Rombak UI input anggota tim menjadi combobox/pencarian *autocomplete*.
  3. Pastikan ketua dan anggota yang sudah ditambahkan tidak muncul lagi di daftar pencarian.
